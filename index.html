Marketplace Inventory Highlighter

A lightweight Tampermonkey userscript that makes Torn City marketplace browsing easier. Track your inventory and display case, highlight item quantities, identify buying opportunities, and keep an eye on Crime and Organized Crime items.

View on GitHub Installation guide ▶ Watch tutorial

About this project

Torn Marketplace Inventory Highlighter is a browser userscript designed to improve the Torn City marketplace experience.

It combines your inventory and display case quantities to calculate how many of each item you own. Marketplace items are automatically highlighted according to your configurable quantity thresholds.

You can also configure maximum buying prices, maintain a personal watchlist, and track items associated with Crimes and Organized Crimes.

No external backend, subscriptions, or third-party services are required. Data and settings are stored locally in your browser.

Installation

  1. Install a userscript manager such as Tampermonkey.
  2. Install the Marketplace Inventory Highlighter userscript from this repository.
  3. Confirm the installation in your userscript manager.
  4. Open Torn City and locate the inventory highlighter panel.
  5. Click 🔑 Key and enter your read-only Torn API key.
  6. Click 🔄 Inventory to retrieve your inventory.
  7. Visit your Display Case and synchronize it using 🏛️ Display Case.
  8. Configure your thresholds and price targets in ⚙️ Settings.

Requirements & notes

  • Torn City account.
  • Tampermonkey or compatible userscript manager.
  • Read-only Torn API key.
  • Internet connection to access Torn.
  • No Node.js server or external database.

Inventory and display case snapshots are saved locally. Refresh them when your item quantities change.

Features

Everything you need to monitor item ownership and identify marketplace buying opportunities.

🎨 Color-Coded Marketplace Highlights

Automatically highlights marketplace and player bazaar items according to your current ownership. Configure global or individual item thresholds.

📦 Inventory + Display Case Tracking

Combines your inventory and display case quantities to calculate total item ownership. Hover over highlighted items to see the breakdown.

💰 Price Target Alerts

Set maximum buying prices for individual items. Prices at or below your targets pulse bright green to identify potential bargains.

⭐ Personal Watchlist

Track items you want to purchase even when you currently own none. Configure buying targets and receive the same price alerts.

📋 Crime & OC Items

A dedicated tab for Crime and Organized Crime items. Identify missing items and review items filtered or associated with Crimes and OCs.

📊 Items Management Panel

Search, filter, and sort tracked items. Manage inventory quantities, display case quantities, thresholds, price targets, and your watchlist.

🖥️ Customizable Interface

Drag, collapse, hide, or show the panel. Your panel position, visibility, and settings are saved between browser sessions.

🔒 Local Data Storage

Your API key, snapshots, watchlist, and settings are stored locally using Tampermonkey's GM_setValue storage API.

API usage

The script is designed to minimize API consumption. Marketplace highlighting, price alerts, and watchlist functionality rely on locally cached data rather than continuously requesting information from Torn.

Action API requests Description
🔄 Inventory refresh ~25–30 Retrieves inventory data across item categories.
🏛️ Display Case sync 0 Reads the currently loaded Display Case page.
Marketplace highlighting 0 Uses locally cached ownership data.
💰 Price target alerts 0 Uses locally stored price targets.
⭐ Watchlist 0 Uses locally stored watchlist entries.

Refresh cooldown

  • Inventory refresh is manual.
  • A 60-second cooldown prevents excessive API requests.
  • A full refresh uses approximately 25–30 requests.
  • Even refreshing every 60 seconds stays below Torn's 100 requests per minute limit.

Normal usage is significantly lower because browsing the marketplace does not generate additional API requests.

Privacy & security

Privacy is a priority. The userscript is designed to operate entirely within your browser.

  • API key stays local: Your Torn API key is stored in Tampermonkey's local storage.
  • Official API: API requests are sent to Torn's official API.
  • No third-party servers: No external backend or cloud storage is involved.
  • No analytics: No tracking, telemetry, or analytics services.
  • Local configuration: Item quantities, thresholds, watchlists, and price targets remain on your machine.
  • Restricted network access: The userscript uses the @connect api.torn.com metadata directive to restrict permitted API connections.

Recommended API permissions

Use a dedicated read-only API key with the minimum permissions required.

  • User Inventory — required for inventory retrieval.
  • Display Case — optional, as the script reads display case quantities from the page.

Never use a full-access API key for this script.

How to use

1. Synchronize your inventory

Enter your API key and use the Inventory button to retrieve your current item quantities.

2. Synchronize your Display Case

Visit your Display Case and use the Display Case synchronization button to update its snapshot.

3. Browse the marketplace

Item names are automatically highlighted according to your combined inventory and display case quantities. Hover over highlighted items to see the ownership breakdown.

4. Configure buying targets

Set maximum prices for items you want to purchase. Marketplace prices that meet your targets receive a bright green pulsing highlight.

5. Manage your watchlist

Add items you want to purchase, even if you currently own zero. Configure their buying targets independently.

6. Check Crime & OC Items

Open the dedicated tab to review Crime and OC-related items, identify missing items, and see which items have been filtered or associated with these activities.

7. Customize your panel

Drag, collapse, hide, or show the interface. Your preferences and panel position are saved locally.
